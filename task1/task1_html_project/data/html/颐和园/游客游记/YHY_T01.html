上周六到颐和园,时间充裕,游得从容,既有一些新发现,又激起不少回忆,整理一下,发现我和颐和园还颇有几分缘. 一,游园之缘 第一次到北京,来的就是颐和园,说起来已是30年前的事了.当时正在河北徐水老家上初中,父亲在县检察院工作,单位组织了一次带家属旅游,本来要去的是著名的万里长城--八达岭,却赶上那天小雨淅沥沥下个不停,于是临时改去颐和园. 水波荡漾的昆明湖,烟波缭绕的万寿山,白虹卧波的十七孔桥,曲曲折折的长廊,还有雨打在镇水铜牛背上溅起的朵朵水花,就成为十几岁少年对首都北京的人生初体验.深深被这儿的山水人文打动,回家后向村里的同学,伙伴念叨良久,好像还写了一篇游记和小诗纪录,那应该是人生的第一首诗,可惜早忘记写什么了. 1996年从西安交大毕业,找工作还不像现在这样四处投简历面试或者拼爹,实行的是双向选择,有幸被国有特大型企业-燕山石化公司录用.在刚入职的厂史教育里,听老一辈燕化人讲过去的故事,当年为了保障燕化的生产用水,用的是密云水库的水,通过京密引水渠到颐和园,又专门修了一条从颐和园到燕山的"百里水线".想不到偏居京郊西南房山的燕化还与颐和园有这样的亲密联系,竟然无由地感到亲切.听早几年入厂的同事说,燕化动力厂在颐和园还有一个小院,可以开会,疗养,还经常组织一些写报告和重要材料的人去那里封闭写稿,想想在那样的怡人山水中创作,别有一番滋味,真真羡煞人也! 但那已经是上世纪的事了.新世纪初,北京水资源紧张,密云水库水位告急,国家抓紧建设南水北调工程,同时燕化也和房山一起开始建设"引拒济燕"工程,把流经十渡的拒马河水引到燕山,除了保障燕化生产和生活用水之外,还通过管线返输北京市,满足西南地区沿线居民生活用水,工程后来应该叫"引拒济京"了. 颇为巧合的是,当时一位名叫"颐和"的王主任与主管调研的副主任把我从下面的二级厂调到燕化公司总经理办公室从事调研文字工作,在几次汇报材料中都提到"百里水线"和"引拒济京"水利工程,既体现了当初北京市对建设燕化的高度重视,也体现出燕化履行社会责任,为北京居民用水服务的积极努力. 随着我在燕化娶妻生女,成家立业,父母来北京燕山与我同住了几年,我也过了一段安居乐业的日子.在周末,经常扶老携幼到北京各处景区玩,八达岭,故宫,中山公园,鸟巢,恭王府,周口店等等,当然也少不了重游颐和园.记得还是早春天气,从北宫门进颐和园,苏州街下面小河的冰还没有完全解冻.遥想乾隆皇帝当年,屡下江南,被南方美景打动,以给母亲祝寿的名义修建清漪园,专门仿建苏州街,在北方也能体验一下南方的市井人文.这样说来,过去的皇上常出去游山玩水也不错,起码开阔了视野,提高了审美,再加上"以孝治天下"的名义,才有了今日颐和园的美景. 那次是从万寿山的后山攀岩而上佛香阁,山石陡峭,70来岁的父母兴致高昂,特别是二老携手上下台阶的背影让我感动,抓拍了几张.父母金婚纪念时,姐姐提议做一个相册,把家里的老照片搜罗整理,哥哥赋诗好几首,其中也收录了这张牵手的照片.(前两天和父母说起此事,已经80岁的爸爸博闻强记,说这个照片是在中山公园拍的,不是颐和园,好吧,听老爸的没错,但我相信,在颐和园上山时二老也是这么牵手滴!) 二,水源之缘 2014年10月,一纸调令把我从公司机关调到水气中心,所辖一供水车间就是负责颐和园取水和田村山净水的地方.上任伊始当然要做一番调查研究,于是第一个去的基层车间就是一供水,亲眼看到了颐和园西门附近的燕化取水闸.看了多年的老图片,写了多少份材料介绍的我终于看到了真正的"百里水线"之源,虽然露在外面的只是两个直立的铁柱,但还是心潮起伏,认真听老师傅介绍情况,说起取水口检修时管道里还有不少大鱼呢.至于原来动力厂曾经占用的小院,已经在颐和园申报世界文化遗产时清退了,恢复了历史原貌,就是现在的"畅观堂". 后来多次进出颐和园,每次都有同样的亲切和不一样的发现.特别是随着燕化公司的改革重组,合资成立京源水务公司,我与200多名燕化职工一起见证和参与了一个新公司的诞生,不管是颐和园取水站的电气检修还是泵房建设,还有卢沟桥上两条悬空水线的防汛演练,都曾深度参与,算是与这条连接燕山和颐和园的百里水线结下了不解之缘.在京源公司读书会的一次交流中,我还想出了一幅小对联与大家分享:"燕山田村山,颐和拒马河",一条线连着两个山,两个河(和),这就是京源之源. 还有一次与朋友从昆玉河坐船到颐和园南如意门,据说这就是过去慈禧太后到颐和园最常走的水路.翻过高高的绣漪桥,沿着水边走上西堤,看着两旁的垂柳和水里的荷花,心里不禁一转念,这不就是杭州的西湖么?当时天朗气清,霞光明媚,景明楼前鸟儿飞翔,好一番"落霞与群鸟齐飞,湖水共长天一色"的绝美景象. 2014年底"南水北调"中线工程全线通水,从丹江口流来的长江水经过1432公里长途自流,终点就是颐和园的团城湖,为此专门修了一个占地70多公顷的调节池,从此北京人民吃上了长江水,而且还可以通过京密引水渠给密云水库补水.颐和园团城湖连接密云水库和长江水,成为京城最大的供水枢纽,号称"京城大水缸",这真是一块风水聚集之地. 从十七孔桥上南湖小岛,有屋"澹会轩",乾隆皇帝认为:水中蕴含动,静,物,理,动由物生,理因静得;四者合一,方为澹会".这位好大喜功,游山玩水的皇帝对水的领悟还是颇深的,但他肯定想不到200多年后伟大的中国人民能够把长江水引到颐和园吧?水何澹澹,会于颐和,南水北调,千里水线,此为水源之缘. 三,线网之源 最近一次到颐和园是骑自行车,与外甥一起从田村山出发,1个小时到颐和园.这是外甥到北京工作实习一年后第一次到颐和园,我劝他没事应该多到北京风景名胜转转,深度感受一下这里的历史人文. 走高桥,穿长堤,登山石,仰望玉泉山,鸟瞰昆明湖,游那曲曲折折的长廊,舅甥二人边走边聊,风景还是那个风景,人已经换成了下一代.这一次的新发现是"皇家电话专线展",在"水木自亲"楼里,原来第一条皇家御用电话专线就是从颐和园到中南海的.话说光绪25年(1899年),时任督办电政大臣的宣怀奏请"由中国电报总局开办电话"的奏折,文中所言"德律风"就是电话(telephone的音译).1902年10月,慈禧与光绪自西安回到经过八国联军烧杀劫掠之后的北京,常驻颐和园,深感现代通信工具之必要性,于是开始架设北京城外务部到京西万寿山的电话,用于外交事务和军事联络.1908年,自颐和园水木自亲到中南海西苑架设专线电话,专备上用,使颐和园成为当时的政治军事和外交指挥中心. 盛宣怀,一个交大人熟悉的名字,近代中国北洋大学和南洋公学就是他倡导建立.虽然对其人的评价不一,但作为洋务运动的核心人物之一是毋庸置疑的,算得上是第一代资本家,一生经历传奇,创办了许多开时代先河的事业,涉及轮船,电报,铁路,钢铁,银行,纺织,教育诸多领域,应该算是北洋军阀时代赫赫有名的"交通系"的源头. 天地交而万物通.从100多年前的电话皇家专线到现在四通八达的网络世界,时代的进步,技术的发展不可谓不大,从当年"德律风"时代的御用专线到现在手机时代的"人人都是麦克风",传播方式,交通手段的变革改变了时代,改变了世界. 末代皇帝溥仪无聊时还曾给新文化运动的大师胡适打过电话,叫他过去聊聊天,见见面,也是一桩趣谈.在颐和园的图片展中,还看到经历过劳动改造之后的溥仪自己缝衣服的照片,曾经的万岁爷成为自己动手的普通公民,在历史大潮的变迁中一个人的变化也是跌宕起伏的. 时代在变,人也要变,有应时而变,也有不得不变.伟大领袖说得好:"牢骚太盛防肠断,风物长宜放眼量.莫道昆明池水浅,观鱼胜过富春江". 颐和园里还有知鱼桥,来自庄子和惠施的对话:"子非鱼焉知鱼之乐?"白马非马,非鱼知鱼,知之为知之,不知为不知,是知也. 那天游园出门,乘兴来到颐和园取水站,与在这里工作30多年的老班长聊天,提起这个"电话专线",他却没什么印象.也许,每个人眼里发现的风景都是他心里所想的吧. 以后,还要常去颐和园看看.
