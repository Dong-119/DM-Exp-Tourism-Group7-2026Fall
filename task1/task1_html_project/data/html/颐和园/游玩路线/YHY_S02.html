　　这是一篇颐和园的老人半日游教学攻略。 假设同行长者可以连续步行约二十分钟，计划10:00入园、13:30结束，园内以步行为主，步行上限与时刻仅是用户约束。这里不声称任何园路都适合轮椅，也不提供未经核实的无障碍保证。

上午10:00—10:20：东宫门，入园后确认出口和现场指引。10:20—11:00：仁寿殿，观看主要建筑。11:00—11:40：乐寿堂，参观后休息十分钟；这十分钟包含在本时段内。

中午11:40—12:40：在乐寿堂之后的现场允许休息地点休息、用餐，不把“休息点”当作一座命名建筑。下午12:40—13:30：按当天开放通道向北宫门离开。它是计划出口，不是新的景区。

计划链路：东宫门 → 仁寿殿 → 乐寿堂 → 休息 → 北宫门。这是一条删减停留点的方向性计划，不承诺节点之间直接相邻；是否可达需查询当天导览。

如果带老人，则每连续步行二十分钟安排一次休息，并删减佛香阁支线。若老人明确表示疲劳，就优先离园，不再增加拍照任务。假如同行者使用轮椅，应先核实无障碍通道；资料没有说明时，不能直接回答“全程无台阶”。

如果只有三十分钟，却希望完整参观所有展区，那么这两个约束冲突；应缩减目标或延长时间，而不是把所有停留压缩到几分钟。这里的二十分钟是建议上限，不是景点开放时长。
