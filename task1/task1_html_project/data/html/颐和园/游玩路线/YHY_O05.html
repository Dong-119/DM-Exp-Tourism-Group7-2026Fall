从新建宫门开始，可以先走到湖畔，再通过游船衔接石舫与长廊，最后到东部院落。北京旅游网景区页面推荐的这条路线，参考时长约三小时，适合希望先看水景、再参观建筑的游客。

参考行进顺序：新建宫门>>南湖岛>>十七孔桥>>铜牛>>乘船至石舫>>耕织图景区>>苏州街>>佛香阁>>排云殿>>长廊>>乐寿堂>>玉澜堂、宜芸馆>>文昌院>>仁寿殿>>东宫门。 （约3小时行程）

入园后的前段行程涉及南湖岛、十七孔桥和铜牛。三者是相互关联的湖畔参观节点，具体衔接可以结合园内导览确认，先从岸边观察整体，再在桥与岛之间感受视角变化。拍照时应照顾正常通行，带孩子的同行者也应注意不要在桥边长时间分散。

随后按原推荐线路乘船去石舫。游船是否运行、具体在哪里登船以及是否有相应航线，都要以现场运营信息为准。船程不应被视为永远可用的固定通道，天气变化或排队过长时，应及时重新安排后半程。

抵达石舫后，先去耕织图景区与苏州街，再经过佛香阁、排云殿和长廊，随后去乐寿堂、玉澜堂和宜芸馆，继续参观文昌院、仁寿殿，最后由东宫门离园。湖上与院落之间的转换，是这条行程的主要特点，可以在两段之间安排一次短暂休息。

这是一条起终点不同的线路。进园前除查看游船信息外，还应想好东宫门离园后的返程方式。若当天不乘船，则需要按园内导览重新评估步行距离，不要把标注的三小时直接套用在变更后的行程上。
