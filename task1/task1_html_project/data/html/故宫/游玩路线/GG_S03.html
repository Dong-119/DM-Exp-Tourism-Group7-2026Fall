这篇故宫亲子与天气适配攻略，以上午参观、午间休息和下午弹性调整组织行程。案例中的家庭有一名六岁孩子，计划停留四小时，偏好建筑观察与短距离步行；这些设定用于练习规划，不代表实际游客信息。

上午先从午门进入，参观太和殿和中和殿。中午在允许休息的位置停留，再决定下午是否去珍宝馆。最终出口预设为神武门，只有在通行与体力都允许时才执行整个计划。

如果下小雨且现场仍允许游览，则减少露天停留，按现场指引选择可进入的避雨处；如果出现雷雨或临时闭园，则停止户外行程并服从管理。前一种情形不能被抽成“任何雨天都能进馆避雨”。

若带孩子且孩子已经疲劳，建议先休息，并取消珍宝馆支线；如果仅仅想拍照，可以在太和殿安排短暂停留。这里“想拍照”不是已经拍过照，“可以”也不总是条件触发词。

如果珍宝馆当天未开放，则取消该支线，沿现场开放通道继续参观；不要把旧攻略里的展陈名称当作已经确认的当日安排。

只有体力允许并且相关区域开放，才加入下午支线。除非天气与开放情况得到确认，否则不承诺乘船、登高或进入特定院落。

如果我上次早点出门就好了，但这句话只是在回顾遗憾，不提供可执行建议。建议先看导览图。这一句没有明确条件，不应凭空补成“如果下雨”。

我们可以继续讨论建筑名称，也可以讨论历史。这两句不构成面向天气或游客类型的条件—游览建议。
