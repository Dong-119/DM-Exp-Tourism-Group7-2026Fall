# 任务一结构化字段

主数据：clean_documents.csv / clean_documents.jsonl / clean_documents.json，三者对应同一组独立记录。JSON的未知字段为null，CSV对应空单元格，列表和对象在CSV中使用JSON字符串。

| 字段 | 含义 |
|---|---|
| doc_id | 保留记录的唯一编号；不是去重规则 |
| title | 原HTML中的文章标题；部分是整理标签 |
| scenic_name | 景区名称，默认故宫/颐和园/天坛 |
| text_type | travelogue游记类、route_guide路线类；不表示真实性 |
| provenance_kind | dataset_corpus教师语料、editorial_route_guide路线整理稿、synthetic_teaching教学模拟、official_route_facts官方路线事实重述；unknown表示无法判定 |
| source_name | 数据来源名称 |
| source_url | 数据集或路线参考页链接；模拟稿为null |
| original_article_url | 原文章网页链接；未知则null，数据集链接不冒充原网页 |
| reference_url | 路线整理/事实依据链接；其余可为null |
| source_published_at | 原来源/参考页日期统一为YYYY-MM-DD；不是采集时间或整理稿发布时间 |
| author | 原作者；无法核实保持null |
| source_file/source_row/source_record_id | 教师语料文件、从0开始的行号、源记录编号 |
| content_origin | 正文真实性质说明 |
| input_path | 输入文件相对/用户指定路径；ZIP路径用::分隔 |
| encoding | 本次HTML解码编码 |
| raw_content | 清洗前正文容器内HTML，保留标签和噪声；原文件全文另存raw_records |
| clean_content | 清洗后规范正文，后续任务的唯一推荐文本基准 |
| text | clean_content的兼容别名；不要将二者拼接 |
| clean_sha256/clean_char_count | 清洗正文哈希与字符数（含单个换行） |
| warnings | 非致命警告，如已知乱码删除和可选字段异常 |
| merged_record_ids | 与本记录合并的全部输入编号，含当前保留编号 |
| source_records | 合并记录的来源元数据数组，可还原重复来源 |

原始metadata_original保留原值，规范化日期和来源性质推断不覆盖原始内容。空缺作者等不构成丢弃文章的理由；缺少景区、类型、正文或冲突身份信息则隔离至errors.json，不静默填造。

quality_report中的source_traceable_official_route_facts只是输入来源声明检查；官方全文独立核验值为0。严格区分“代码实现完成”和“来源满足官方原文要求”。
