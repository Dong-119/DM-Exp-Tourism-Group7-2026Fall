## 风险与复现规范

1. **折号不能混用**。本机与服务器可能因为 scikit-learn 版本差异产生不同的 GroupKFold 折号；融合试验按照每条文本的唯一 `id` 对齐 OOF 预测。
2. **类别先验仅来自已知训练集的均衡设计**；隐藏集类比例未知，在小样本场景采取回退。
3. **V6 仍是 transductive 推断**，只访问无标签测试文本；不会读取隐藏测试的 Prompt ID 或真实模型标签。需要单独说明它对 Prompt 组大小的假设较弱。
4. 多轮候选在同一五折上反复调参，存在间接验证集过拟合风险；以后应增加独立来源/时间验证，而不是只提高相同 OOF。
5. 五次 Kaggle 评分均已成功，课程要求的五次有效提交已完成。**线上最佳为 V5（0.417），V6 为 0.411，未超过 V5。官方成绩截图仍需从已登录 Submissions 页面保存**。所有提交日志和 JSON 留在本地 `outputs/kaggle_submission_v5/`、`outputs/kaggle_submission_v6/`，不推送 GitHub。

## 服务器状态

本轮仅使用经授权的 GPU 服务器作为远端 CPU 训练环境；所有公开数据先在本机下载并通过 SCP 上传至独立 Kaggle 实验目录。没有依赖服务器直接访问外网，也没有修改共享 Conda 环境。LightGBM 使用当前进程的系统 C++ 运行库解决兼容问题，不改写全局环境。
