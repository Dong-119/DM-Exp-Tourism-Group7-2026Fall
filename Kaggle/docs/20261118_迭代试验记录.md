# 2026-11-18：Name That LLM 后续实验记录

## A. 无监督恢复 Prompt 组 + Hungarian 分配（成功）

官方 train.csv：150 个 Prompt，149 个 Prompt 各有 18 个不同模型回答，另有一组 17 个，不存在同一个 Prompt 对应重复模型标签的情况。

原始数据按 prompt_id 做五折 GroupKFold；验证时**不使用** prompt_id 进行聚类。仅利用验证文本的词级 TF-IDF 相似度，贪心合并相似样本，且最大簇大小限制为 18。五折实际恢复组的 ARI 均为 **1.0**；此 ARI 仅用于事后审计，不输入分类器。

固定 V2 的线性 SVM margin 不变；对于恢复出的 16–18 条文本的近完整簇，使用 Hungarian 线性分配，限制不同文本分配到不同模型。更小或异常的簇采用独立分类回退。

| Fold | V2 独立 BA | V3 联合 BA | 提升 |
|---|---:|---:|---:|
| 1 | 0.348148 | 0.405556 | +0.057407 |
| 2 | 0.340741 | 0.403704 | +0.062963 |
| 3 | 0.374074 | 0.485185 | +0.111111 |
| 4 | 0.390741 | 0.490741 | +0.100000 |
| 5 | 0.339017 | 0.429885 | +0.090868 |

整体五折 OOF：V2 **0.358553**，V3 **0.443045**。运行记录、各类召回率及 OOF 结果保留在 `outputs/V3_prompt_joint/`，正式版摘要位于 `experiments/V3_prompt_joint/`。

**关键局限**：真实 Kaggle 隐藏测试数据未给 prompt_id，且可能不满足每 Prompt 恰好 18 个模型。验证集结构来自训练集中的完整 Prompt，不代表线上同样完整；线上使用时推断的组错配会损害模型判断。后续需检测近完整组可信度及缺失模型情形，不以公榜过拟合。第三方公开方案中也有类似思路，可参考 https://github.com/jerrythomas/name-that-llm ；本地实现与 OOF 评分均独立执行。
