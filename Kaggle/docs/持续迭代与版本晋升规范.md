# 持续迭代与版本晋升规范（2026-11-18 起）

## 目标与授权

目标只有一个：在**遵守比赛规则、没有数据泄漏**的前提下，持续提高 Name That LLM 的跨 Prompt Balanced Accuracy。

- 可以直接开展后续实验、调参、模型训练及评估；服务器空闲时可使用 GPU，无须每轮询问。
- 允许在一次正式版本之间进行多次小实验、否定实验和参数搜索；**不要求每次实验都升级版本**。
- 只在充分验证后才正式晋升为 V2、V3……；未晋升的尝试保留简明实验记录，便于复现和回顾。
- 不为增加版本号而降低科学性；不会修改原始数据，不会把测试标签或 Kaggle 公榜当成调参训练数据。
- 避免大范围占满共享 GPU：先检查 `nvidia-smi`，按需使用空闲卡；优先单卡实验，已有训练任务不抢占；结束释放显存与进程。
- 不创建长期驻留的后台训练、监控或无限期进程；当前对话可以同步运行任务并验证，长任务只在可跟踪的会话中执行。

## 固定评价协议（横向可比）

- 主要指标：**五折 GroupKFold 的整体 OOF Balanced Accuracy**（18 类平均召回率），按 `prompt_id` 划分，所有模型共用同一份 split。
- 每折训练/验证集合的 `prompt_id` 必须完全不相交；特征提取、向量化、标准化、模型拟合均只用该折训练集拟合。
- 必须同时记录：五折各分数、整体 OOF、类别召回率、混淆矩阵、运行环境、参数、数据哈希、时间与代码版本。
- 首轮已完成 V1，最优 `char_svc` 的 OOF BA 为 **0.307813**，作为固定对照。
- 反复试验会逐渐使验证集被间接过拟合。后续大规模参数搜索时，增加独立的 Prompt 留出集、重复分组划分或额外独立数据复核，不只看单份 CV 上的差异。

## 版本晋升（实操门槛）

- 临时试验命名为 `trial-YYYYMMDD-XX`，或记入当轮 `trials.csv`，不一定同步 GitHub。
- 候选方案在完整五折上相对当前正式版本**整体 OOF BA 提高至少 0.02（2 个百分点）**，且排除数据泄漏、异常训练和明显的类别崩溃，优先晋升新版本。
- 提升低于 0.02 但经多种划分验证稳定、有可解释互补性时可以作为候选保存；不宣称“显著提升”。
- 晋升后冻结代码、关键参数、数据哈希和综合指标，产生 `experiments/Vx/summary.md` 与 `metrics.json`，同步至团队 Git 仓库；大模型权重、日志、逐条预测及 ZIP 只存本地/服务器。
- **本地 CV 成绩 != Kaggle 公榜成绩 != 最终私榜成绩**，三者单独管理；正式提交后记录 Notebook 版本、Submission ID、分数及截图，务必保留课程要求至少五次有效提交的证据。
- Kaggle 正式提交由队内指定负责人统一管理；不要自动提交、自动修改队伍或自动推送 GitHub 远端。

## 每轮工作流

1. 看上一轮的逐类召回率和混淆，制定一个优先验证的假设。
2. 本地先跑快速探索，记录失败与成功；需要 GPU 时检查服务器空闲和现有环境，避免干扰其他项目。
3. 在固定五折下完整复验最好的候选，检查按 Prompt 分组、数据哈希与每折样本覆盖。
4. 对比当前最佳正式版本，超过晋升门槛则冻结新版本，未超过则作为 trial 留档继续探索。
5. 仅向 GitHub 的 `Kaggle/` 同步白名单内的可复现代码、精选汇总、实验说明；不提交原始数据、模型权重或敏感信息。
6. 团队正式提交 Kaggle 后补齐真实证据，未提交的实验写“未提交”，不可凭空编造分数/截图。

## 运行资源

- 本地可执行传统方法与轻量训练；服务器 SSH 别名 `srp-sirna` 指向已授权 GPU 服务器，可先用 `nvidia-smi` 判断资源状态。
- **已验证离线服务器工作流**：本机从 Hugging Face/PyPI 下载公开 DeBERTa-v3-base 权重与 Linux Python3.9 wheels，使用 SCP 上传到服务器独立的 `kaggle-name-that-llm-2026/` 实验目录，只在独立目录安装 Transformer 依赖，不修改共享 Python 环境。四张空闲 RTX 3090 并行完成四折微调；但分数低于 V2，故不晋升。下载缓存及验证记录保留在本地 outputs/ 与服务器实验目录。
- 所有 GPU 训练在独立目录，避免覆盖既有科研项目与用户其他进程。

- V1：`word_lr` OOF BA 0.272247；`char_svc` OOF BA 0.307813。
- V2：**已晋升正式版本**，词级 + 字符级 TF-IDF + 110 项写作风格统计特征，整体 OOF BA **0.358553**；相对 V1 **+0.050740**，且五折均提升。详见 `experiments/V2_feature_fusion/`。Notebook 已构建并通过本地 3 条测试样本推理检查，Kaggle 正式提交及公榜成绩仍待完成。
